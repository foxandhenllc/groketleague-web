# Kitchen Sink home flow — 2026-09-27

## Player-facing change

Fresh visits open **3D Kitchen Sink vs Grok**. Pick a vehicle image and press **Play Kitchen Sink**; the extra setup screen and automatic tutorial popup no longer interrupt this path. Existing saved 2D preferences cannot override the new default. Deliberate alternative selections remain active until reload and carry through rematches.

**Match options** keeps the alternatives accessible through buttons: Kitchen Sink/Stadium image cards, 3D/2D, stadium Day/Night, Solo/Find a match/With a friend. Returning home updates its preview and Play label to the selected arena. Private invite links open the correct panel with the code already filled in. Pending matchmaking locks arena/view choices to preserve the host setup.

Car details, How to play, audio and account controls have optional buttons. Home shows the boost control without requiring help. Keyboard users can activate menu buttons with Space or Enter; the help dialog keeps focus and closes with Escape. The primary Play action stays inside the visible panel down to 320×568 portrait and 568×320 landscape.

## Implementation

- `index.html`, `garage.css`: compact launch panel and image/button choices; no setup selects or details menus.
- `main.js`: default, direct launch, synchronized preview/labels, optional help and invite routing.
- `input.js`: setup controls retain native keyboard behavior instead of consuming Space as boost.
- `assets/menu/*.webp`: six previews rendered from the actual arena and vehicle meshes. Regenerate with the local server on port 5198 and `node tests/render-garage-previews.mjs`.
- Existing browser/capture scripts explicitly choose their intended arena so the new default does not silently change their coverage.
